🔧 ROOT CAUSE & SOLUTION

  Problem: Model had conflicting suppress_tokens configuration that caused
           bizarre repetitions in output despite good WER metrics.
  
  Solution: Explicitly disable suppress_tokens and begin_suppress_tokens
            before model.generate() calls:
            
            model.generation_config.suppress_tokens = None
            model.generation_config.begin_suppress_tokens = None

  Impact: Immediate elimination of repetition artifacts + 6% WER improvement

  1. Activate virtual environment:
     & "./.venv/Scripts/Activate.ps1"
     $env:PYTHONIOENCODING='utf-8'

  2. Transcribe audio file:
     python cli/transcribe.py --audio "path/to/audio.mp3"

  3. With custom output:
     python cli/transcribe.py --audio "audio.mp3" --output "result.txt"

  4. Override generation parameters:
     python cli/transcribe.py --audio "audio.mp3" --num_beams 5 --temperature 0.5
