Spremni fajlovi (lokalno)

speech_recognation_code_for_kaggle.zip — kompletan code-only paket (najvažniji)
kaggle_bundle_minimal.zip — minimalni paket skripti/notebooka
Kaggle_Full_ASR_Run.ipynb — gotov notebook za upload
Apsolutno svi koraci (od sada, od nule, za v1/v2/v3)

1) Prvi put: napravi Kaggle Dataset sa kodom

Otvori Kaggle → Datasets → New Dataset.
Upload: speech_recognation_code_for_kaggle.zip.
Nazovi npr. speech-recognation-code.
2) Prvi put: napravi Kaggle Dataset sa raw podacima

Kaggle → Datasets → New Dataset.
Upload tvoj raw sadržaj (audio + txt parovi).
Nazovi npr. speech-recognation-raw.
3) Kreiraj Notebook

Kaggle → Code → New Notebook.
Settings:
Accelerator = GPU (T4)
Internet = ON
4) Attach Input datasets u notebook

Klik Add data i dodaj:
speech-recognation-code
speech-recognation-raw
Za v2/v3 ćeš dodavati i output dataset iz prethodne verzije (objasnio dole).
5) Upload gotov notebook

U notebook-u uradi upload fajla Kaggle_Full_ASR_Run.ipynb, ili copy/paste ćelije iz njega.
Pokreni ćelije redom.
v1 run (full pipeline)

6) U ćeliji 4 promeni samo putanju

RAW_DIR = '/kaggle/input/<slug-raw-dataseta>/data/raw'
Ostale parametre ostavi za početak:
epochs 8
batch 8
lr 2e-6
7) Pokreni ćelije 1 → 6

To radi:
bootstrap code
install deps
env check
full alignment+train+strict holdout eval
summary metrika
8) Pokreni ćeliju 7

Pravi zip artefakata v1 u /kaggle/working.
9) Sačuvaj rezultat da ne nestane

Klik Save Version notebook-a.
U Data sekciji notebook output-a napravi novi Dataset iz /kaggle/working artefakata.
Nazovi npr. asr-full-run-v1-output.
v2 run (dotreniranje iz v1)

10) Napravi NOVI notebook run (ili dupliraj postojeći)

Opet GPU T4 + Internet ON.
Attach datasets:
speech-recognation-code
speech-recognation-raw (nije obavezno za čisto continue, ali može ostati)
asr-full-run-v1-output
11) U ćeliji 8 podesi

PREV_RUN_V1 = '/kaggle/input/<slug-v1-output>/asr_full_run_v1'
Pokreni ćeliju 8.
12) Export i čuvanje v2

Ćelija 8 već pravi zip v2.
Save Version.
Objavi output kao dataset npr. asr-full-run-v2-output.
v3 run (dotreniranje iz v2)

13) Novi notebook run

Attach:
speech-recognation-code
asr-full-run-v1-output (za aligned_train)
asr-full-run-v2-output (za model)
14) U ćeliji 10 podesi

PREV_RUN_V2 = '/kaggle/input/<slug-v2-output>/asr_full_run_v2'
train_data_v1 = '/kaggle/input/<slug-v1-output>/asr_full_run_v1/aligned_train'
Pokreni ćeliju 10.
15) Sačuvaj v3

Save Version.
Objavi output dataset npr. asr-full-run-v3-output.
Da li svaki put moraš sve ponovo da upload-uješ?

Ne.
Code dataset i raw dataset upload-uješ jednom.
Posle svakog run-a samo dodaš novi output dataset iz prethodne verzije (v1→v2, v2→v3).
Praktično pravilo za verzije

v1: full pipeline (run_full_pipeline.py)
v2: continue (continue_training.py na modelu iz v1)
v3: continue (continue_training.py na modelu iz v2)
